# Rohmaterial

Ablage für unverarbeitetes Material: Aufsätze, Vortragsmanuskripte, Folien, Merkblätter,
Checklisten, Diktate.

Der Ordner ist bewusst formlos — hier muss nichts sortiert oder benannt werden. Aus dem,
was hier liegt, entstehen die strukturierten Themen unter `../themen/`. Die Rohdateien
bleiben liegen, damit später nachvollziehbar ist, worauf ein Thema beruht.

**Nichts Mandatsbezogenes.** Keine Akten, keine Entwürfe für konkrete Mandanten, keine
echten Namen oder Zahlen aus laufenden Sachen — § 43a Abs. 2 BRAO, siehe
[`../../BERUFSRECHT.md`](../../BERUFSRECHT.md).

Grosse Binärdateien (Scans, Videos) gehören nicht in die Versionsverwaltung. Wenn viel
davon zusammenkommt: vorher Bescheid sagen, dann wird ein eigener Weg dafür eingerichtet.
